# ML Android Lab

ML Android Lab is a demo application showcasing the implementation of various machine learning techniques on Android, using frameworks like ML Kit, TensorFlow Lite, MediaPipe, Firebase Machine Learning, and Generative AI, all developed with Kotlin and the latest best practices.

## Features

### ML Kit
1. **Text Recognition**: Detect and extract text from images in real-time.
2. **Barcode Scanning**: Scan and process barcodes from live camera input.

### TensorFlow Lite
3. **Image Classification**: Classify objects in images using pre-trained models.
4. **Prediction**: Make predictions using custom-trained TensorFlow Lite models.

### MediaPipe
5. **Image Classification with MediaPipe**: Leverage MediaPipe for advanced image classification.
6. **Audio Classification**: Classify different types of audio data.
7. **Sentiment Text Classification**: Perform sentiment analysis on text data using MediaPipe.

### Firebase Machine Learning
8. **Custom Model Deployment**: Deploy and use custom machine learning models hosted on Firebase.

### Generative AI
9. **Smart Reply with ML Kit**: Generate contextually appropriate replies based on input text.
10. **BERT Question & Answer**: Implement BERT (Bidirectional Encoder Representations from Transformers) for answering questions based on input text.

## Tech Stack
- **Programming Language**: Kotlin
- **Jetpack Components**
- **Machine Learning Frameworks**:
  - **ML Kit**: Google’s machine learning SDK.
  - **TensorFlow Lite**: A lightweight machine learning framework for mobile and edge devices.
  - **MediaPipe**: For building multimodal machine learning pipelines.
  - **Firebase Machine Learning**: To deploy custom models easily.
  - **Generative AI**: Utilizing ML Kit and TensorFlow Lite for smart replies and question answering.
